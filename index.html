使い方
  1. StopWatch の設定で Bluetooth を入れる（「常に」）。
  2. 上のボタンを押し、一覧から「M5 StopWatch」を選ぶ。
  3. 初めてのときはペアリングを求められるので許可する。
  4. StopWatch が短く振動したら完了。

Android の Chrome、Windows の Chrome / Edge で使えます。Linux の Chrome では Web Bluetooth が既定で無効のことがあります。
